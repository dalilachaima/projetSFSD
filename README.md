# Système de Gestion des Fichiers simplifié :

Réalisé par un groupe de 6, ce projet implémente la manipulation des fichiers en language C, 
permettant de les stocker et les organiser sur la mémoire secondaire afin de comprendre les concepts fondamentaux de la gestion des fichiers.


## Overview :
Ce projet a été conçu pour apprendre et bien comprendre les bases de la gestion des fichier et des données dans les mémoires secondaires. Il permet d'exécuter des opérations de base comme la création modification et suppression des fichiers, l'insertion la recherche et la modification des données... 

L'objectif principal est de permettre au programme de manipuler des fichiers de manière efficace et d'interagir avec le système des fichier pour stocker les données de manière persistante.


## Fonctionnalités : 
- La manipulation des fichiers de données ( création, suppresion, modification)
- La manipulation des fichiers de métadonnées ( affichage, modification et mise à jour )
- La manipulation des données ( intialisation de la mémoire secondaire, l'allocation des blocs , insertion recherche et suppression des enregistrements, le compactage et la réinitialisation de la mémoire secondaire)
- Un menu interactif clair, simple et facile à utiliser


## Installation et Exécution :

#### Prérequis : 
Assurez vous d'avoir un éditeur de code comme Dev C++, VSCode, ou tout autre éditeur de développement en C installé sur votre ordinateur.

#### Télécharger le code source : 
télécharger le fichier .c du projet.
Ouverez le fichier sur votre éditeur : Lancez l'éditeur que vous voulez puis ouvrez le fichier .c téléchargé.

#### Compilez et exécutez : 
cliquez sur le bouton Run. Dans le cas d'utilisation de VSCode, assurez vous d'avoir téléchargé les extensions nécessaires pour la programmation en C
